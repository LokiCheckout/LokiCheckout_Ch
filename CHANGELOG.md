## [1.0.0] - 27 November 2026
### Added
- Swiss (CH) address settings for the Loki Checkout: street fields labelled Street Name, Housenumber and Addition, a 4-digit postcode field with input mask, and the region field labelled Canton
- A compact layout for the house number and addition fields in the default skin
- A Swiss grid layout so the country field spans the full width

### Fixed
- The Swiss settings now apply to both billing and shipping addresses, through the new address-specific and country-specific layout handles
